# Справочник форм автомобилей

Учебный веб-проект: интерактивный каталог типов кузова автомобилей с системой фильтрации, галереей и полноценной административной панелью. Реализован на чистом HTML, CSS и JavaScript без использования серверной части.

## Демо
🔗 **Публичная ссылка:** https://github.io

## Основной функционал
- **Каталог кузовов:** отображение карточек с постраничной навигацией (по 6 записей на страницу).
- **Поиск и фильтрация:** живой поиск по названию и фильтрация по категориям («Легковые», «Внедорожники», «Грузовые»).
- **Страница автомобиля:** подробное описание, счётчик просмотров и интерактивная галерея изображений.
- **Админ-панель:** закрытый раздел с авторизацией и хешированием пароля (SHA-256 через Web Crypto API).
- **Управление контентом:** создание, редактирование и удаление карточек, управление категориями и сброс к демо-данным.
- **Работа с изображениями:** загрузка главного фото и галереи (JPG, PNG, WEBP размером до 500 КБ) с предпросмотром.

## Доступ в панель администратора
- **Логин:** `admin`
- **Пароль:** `admin123`

## Используемые технологии
- **HTML5 / CSS3:** семантическая вёрстка, CSS Grid, Flexbox, CSS-переменные и адаптивный дизайн.
- **JavaScript (ES2017+):** SPA-роутинг на основе хеша (`location.hash`), асинхронная обработка файлов.
- **Браузерные API:** `localStorage` для хранения базы данных, `sessionStorage` для сессии администратора, `FileReader API` для кодирования изображений в Base64 и `Web Crypto API`.

## Локальный запуск
1. Скачайте репозиторий или клонируйте его командой `git clone`.
2. Откройте файл `index.html` в любом современном браузере (при первом запуске демо-данные сгенерируются автоматически).
